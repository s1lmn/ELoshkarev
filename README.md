# In-memory база данных

Проект реализует простую in-memory базу данных с одной таблицей `Student`. Данные хранятся только в оперативной памяти и доступны во время работы программы.

## Структура проекта

```text
PIOA-НомерГруппы/
├── src/
│   └── db/
│       ├── __init__.py
│       ├── __main__.py
│       ├── tui.py
│       └── backend/
│           ├── __init__.py
│           └── memory.py
└── README.md
```

## Назначение модулей

- `src/db/__main__.py` - точка входа в приложение.
- `src/db/tui.py` - консольный интерфейс для ввода команд и вывода результатов.
- `src/db/backend/memory.py` - in-memory таблица `Student` и функции добавления/чтения записей.

## Реализованная функциональность

- одна таблица `Student`;
- добавление записей;
- чтение всех записей;
- чтение записей с фильтрацией по одному или нескольким полям;
- обработка ошибок:
  - отрицательный возраст;
  - дублирующийся `id`;
  - некорректный ввод числа.

## Предметная область

Таблица `Student` содержит поля:

- `id` - уникальный идентификатор;
- `first_name` - имя;
- `second_name` - фамилия;
- `age` - возраст;
- `sex` - пол.

## Запуск проекта

```bash
python3 -m src.db
```
