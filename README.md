## Описание проекта

Проект представляет собой прототип базы данных, работающей в оперативной памяти.  
Приложение запускается в консоли и позволяет:

- создавать таблицы;
- добавлять записи;
- читать записи с фильтрацией по одному или нескольким полям;
- обновлять записи;
- удалять записи;
- обрабатывать ошибки, связанные с некорректным вводом, отсутствующими таблицами и несуществующими записями.

Реализация покрывает не только основную задачу, но и дополнительную: поддерживает несколько таблиц и полноценный CRUD.

## Реализованная функциональность

### Основная часть

- Одна in-memory база данных с таблицами, которые пользователь создаёт во время выполнения программы.
- Добавление записей в таблицу.
- Чтение записей с фильтрацией по одному или нескольким полям.
- Обработка ошибок:
  - неверные типы данных;
  - неизвестные поля;
  - попытка обращения к несуществующей таблице;
  - попытка добавить запись с уже существующим первичным ключом;
  - попытка обновить или удалить несуществующую запись.
- Простой консольный интерфейс.

### Дополнительная часть

- Обновление записей.
- Удаление записей.
- Создание и использование нескольких таблиц.

## Поддерживаемые типы полей

- `int`
- `float`
- `str`
- `bool`

Для булевых значений поддерживаются варианты: `true/false`, `yes/no`, `1/0`, `да/нет`.

## Инструкция по запуску

### Требования

- Python 3.10 или новее

### Запуск

```
python3 main.py
```

## Пример сценария работы

1. Создать таблицу `books`.
2. Добавить поля:
   - `id` типа `int`
   - `title` типа `str`
   - `author` типа `str`
   - `year` типа `int`
3. Назначить `id` первичным ключом.
4. Добавить записи.
5. Выполнить чтение с фильтрацией, например по полям `author` и `year`.

## Особенности реализации

- Все данные хранятся только в памяти и исчезают после завершения программы.
- Код разделён на небольшие модули по ответственности.
- Для основных ошибок используются отдельные классы исключений.
