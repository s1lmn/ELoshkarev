# In-memory база данных: ООП и тестирование

Проект представляет собой объектно-ориентированную переработку лабораторной работы 2. База данных работает в оперативной памяти и содержит одну таблицу `Student`.

## Структура проекта

```text
ELoshkarev/
├── src/
│   └── db/
│       ├── __init__.py
│       ├── __main__.py
│       ├── tui.py
│       └── backend/
│           ├── __init__.py
│           ├── errors.py
│           └── memory.py
├── tests/
│   ├── __init__.py
│   ├── test_main.py
│   ├── test_memory.py
│   └── test_tui.py
└── README.md
```

## Назначение модулей

- `src/db/backend/memory.py` - класс `StudentTable` и операции создания/чтения записей.
- `src/db/backend/errors.py` - пользовательские исключения.
- `src/db/tui.py` - текстовый интерфейс, реализованный с использованием класса `TUI`.
- `src/db/__main__.py` - точка входа в приложение.
- `tests/` - автоматизированные тесты.

## Реализованная функциональность

- объектно-ориентированная реализация таблицы `Student`;
- добавление записей;
- чтение записей с фильтрацией по одному или нескольким полям;
- обработка ошибок через пользовательские исключения;
- консольный интерфейс на основе класса;
- автоматизированные тесты.

## Запуск проекта

```bash
python3 -m src.db
```

## Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```

## Проверка покрытия

Если установлен `coverage`:

```bash
python3 -m coverage run -m unittest discover -s tests
python3 -m coverage report -m
```
