## Описание проекта

Проект представляет собой консольный прототип системы управления данными, работающей полностью в оперативной памяти.
Реализация выполнена с использованием классов и поддерживает создание нескольких таблиц, полноценные CRUD-операции,
фильтрацию и сортировку записей.

## Структура проекта

```text
project_root/
├── main.py
├── README.md
├── inmemory_db/
│   ├── __init__.py
│   ├── cli.py
│   ├── database.py
│   ├── exceptions.py
│   ├── io_handler.py
│   ├── models.py
│   └── table.py
└── tests/
    ├── __init__.py
    ├── test_cli.py
    ├── test_database.py
    ├── test_main.py
    ├── test_models.py
    └── test_table.py
```

## Назначение модулей

- `main.py` - точка входа в приложение.
- `inmemory_db/cli.py` - консольный интерфейс, построенный на классах.
- `inmemory_db/io_handler.py` - классы для работы с пользовательским вводом и выводом.
- `inmemory_db/database.py` - управление набором таблиц.
- `inmemory_db/table.py` - CRUD-операции, фильтрация и сортировка.
- `inmemory_db/models.py` - схема таблицы, описание полей и преобразование типов.
- `inmemory_db/exceptions.py` - пользовательские исключения.
- `tests/` - автоматизированные тесты.

## Реализованная функциональность

- создание нескольких таблиц;
- добавление записей;
- чтение записей с фильтрацией по одному или нескольким полям;
- обновление записей;
- удаление записей;
- сортировка записей по выбранному полю по возрастанию и убыванию;
- обработка ошибок при некорректном вводе, неверных типах, отсутствии таблиц и записей;
- консольный интерфейс, реализованный с использованием классов.

## Поддерживаемые типы полей

- `int`
- `float`
- `str`
- `bool`

Для `bool` поддерживаются значения `true/false`, `yes/no`, `1/0`, `да/нет`.

## Запуск проекта локально

```
python3 main.py
```

## Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```

## Проверка покрытия

Если в окружении установлен модуль `coverage`, можно использовать:

```bash
python3 -m coverage run -m unittest discover -s tests
python3 -m coverage report -m
```

Если `coverage` не установлен, можно воспользоваться стандартным модулем Python:

```bash
python3 -m trace --count --summary --module unittest discover -s tests
```

## Особенности реализации

- данные существуют только во время работы программы;
- логика базы данных и пользовательский интерфейс разделены по зонам ответственности;
- проект покрыт автоматизированными тестами.
