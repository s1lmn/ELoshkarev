# Файловая СУБД на JSON

Проект расширяет объектно-ориентированную систему управления данными из предыдущей лабораторной работы и добавляет файловую СУБД. Программа поддерживает единый интерфейс для `in-memory` и `JSON`-реализации.

Eloshkarev/

## Назначение модулей

- `src/db/backend/table.py` - класс таблицы и операции над записями.
- `src/db/backend/database.py` - общий интерфейс базы данных.
- `src/db/backend/memory.py` - in-memory реализация базы данных.
- `src/db/backend/file.py` - файловая реализация базы данных на JSON.
- `src/db/backend/errors.py` - пользовательские исключения.
- `src/db/tui.py` - текстовый интерфейс и выбор типа базы данных.
- `tests/` - автоматизированные тесты для памяти, файлов и интерфейса.

## Реализованная функциональность

- создание таблиц;
- добавление записей;
- чтение записей с фильтрацией;
- работа с `in-memory` и `JSON` хранилищем через единый интерфейс;
- сохранение таблиц на диск и восстановление после перезапуска;
- обработка ошибок чтения файлов и некорректных пользовательских данных.

## Различия между реализациями

- `MemoryDatabase` хранит таблицы только в оперативной памяти.
- `FileDatabase` сохраняет каждую таблицу в отдельный JSON-файл в каталоге `data/`.

## Запуск проекта

```bash
python3 -m src.db
```
